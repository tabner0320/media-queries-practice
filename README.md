# Responsive Web Design – Media Queries Practice

A responsive web design practice project built with HTML5 and CSS3.

This project demonstrates how CSS media queries, Flexbox, and CSS Grid can be used to create layouts that adapt to different screen sizes, including desktop, tablet, and mobile devices.

---

## Features

- Responsive navigation
- Responsive hero section
- Multi-column desktop layout
- Two-column tablet layout
- Single-column mobile layout
- CSS Grid
- Flexbox
- Media queries
- Responsive typography
- Mobile-friendly spacing
- Semantic HTML structure

---

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic content |
| CSS3 | Styling and responsive design |
| Flexbox | Navigation and layout alignment |
| CSS Grid | Responsive card layouts |
| Media Queries | Adapting the design to different screen sizes |
